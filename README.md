# 희윤이 오늘 할 일 보드 V1.0

초등학교 4학년 희윤이가 해야 할 일의 **순서와 시간을 직접 정하고**, 실제 시작/완료 시간을 기록하는 정적 웹앱입니다.

## 포함 기능
- 오늘 요일에 맞는 미션 자동 표시
- 각 미션 계획 시간 설정
- 실제 시작 / 완료 시각 저장
- 오늘 진행률
- 계획 시간이 정해진 순서대로 타임박스 표시
- 독서: 학습만화 / 글책 선택
- 추천 글책 목록 + 책 제목 기록
- 주간 완료 현황 / 글책 도전 별
- 최근 학습 기록
- 부모 설정에서 학습 요일 변경
- 브라우저 localStorage에 기록 저장

## 기본 주간 설정
- 구몬 국어: 월~금
- 구몬 한자: 월~금
- 큐티: 매일
- 책 읽기: 매일
- 한국사: 월/수/금
- 영어: 화/목/토
- 문해력: 목

부모 설정 화면에서 바로 바꿀 수 있습니다.

## 배포
정적 사이트라 `index.html` 하나만 있어도 실행됩니다.

### GitHub + Vercel
1. 새 GitHub 저장소 생성
2. `index.html` 업로드
3. Vercel에서 해당 저장소 Import
4. Framework Preset: Other
5. 별도 Build Command 없이 Deploy
