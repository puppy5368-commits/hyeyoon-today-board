# 희윤이 오늘 할 일 보드 - 어와나 추가본

추가사항:
- `어와나 말씀 암송` 미션 추가
- 기본 설정은 매일 표시
- 시간 선택/시작 버튼 없이 `오늘 암송했어요` 체크만 제공
- 체크를 다시 누르면 해제 가능
- 부모설정에서 어와나 표시 요일 변경 가능
- 기존 `heeyoon-today-board:v1` 저장 구조는 유지

## 문해력 V2

- 12주 × A(기술 배우기 3문항)/B(실전 적용 4문항): 24회, 새로 작성한 84문항.
- 문장 관계, 어휘, 요약, 추론, 자료, 비교, 인과, 글 구조, 선택지 검증, 복합 독해, 재진단으로 진행합니다.
- 답 선택 → 확신 → 문단/표 근거 선택 → 확인. 첫 오답에는 재독만 안내하고, 두 번째 오답 후 힌트를 열 수 있습니다. 해설을 열면 별도 이해 확인 후 완료합니다.
- 근거 선택은 필수이나 정답 판정은 답 기준입니다. 핵심 근거 누락은 별도 피드백과 부모 기록에서 확인합니다. 핵심 문단을 모두 포함하면 근거 충족으로 기록하며, 추가 문단 선택은 감점하지 않습니다.
- 모든 회차 미리보기 가능. 미리보기에는 새 기록이나 정답/해설이 생성되지 않습니다. 학습 시작 후 문제별 진행을 저장하며 완료 기록은 덮어쓰지 않습니다.
- 부모용 기록은 접힌 영역에 첫 제출 정답률, 재독 해결, 힌트 사용, 확신했지만 오답인 수, 상세 풀이를 표시합니다. ‘첫 선택’은 답 확인을 처음 누른 시점의 답입니다.
- 이번 학습 주차는 첫 미완료 회차 기준이며 달력과 자동 연결하지 않습니다. 1주/12주 비교는 참고용으로, 표준화된 진단 점수가 아닙니다.

### 저장 및 기존 기능 보호

- 메인 `heeyoon-today-board:v1` 구조와 기존 기능은 유지합니다. 신규/문해력 설정 누락 시만 화·목 기본값을 사용하고, 기존 `[4]`, 사용자 지정 요일, 빈 배열을 그대로 유지합니다.
- V2는 `heeyoon-literacy-board:v2`만 씁니다. 기존 `heeyoon-literacy-board:v1` 및 `literacy/data.js`는 보존했습니다. V1 기록은 V2 진도에 합치지 않습니다.
- 저장 실패는 화면에 안내합니다. 읽을 수 없는 V2 데이터는 덮어쓰지 않습니다.
- 문해력 회차 완료와 메인 보드의 오늘 미션 완료는 기존처럼 별개입니다.
- 저장은 브라우저와 주소별입니다. 로컬 테스트 기록은 배포 주소의 기록과 분리됩니다.

### 파일

- `index.html`: 문해력 기본 요일과 이번 주/부모설정 진입 링크만 변경.
- `literacy/index.html`: 기존 디자인 유지, V2 스크립트 연결, 진행률과 부모 기록 및 모바일 스타일.
- `literacy/data-v2.js`: V2 전용 지문·문제·표·근거·힌트.
- `literacy/app.js`: 학습 흐름, 24회 탐색, 독립 저장, 부모 기록.
- `scripts/serve.cjs`: 외부 의존성 없는 로컬 전용 서버.
- `scripts/test.cjs`: 콘텐츠 무결성, 풀이 흐름, 모든 회차 완료, 저장 복원, 기존 설정 보호 자동 검증.

### 실행

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
node scripts/serve.cjs
```

메인: http://localhost:4173/ · 문해력: http://localhost:4173/literacy/

검증: `node scripts/test.cjs`

### 학습 진행 UX 보완

- 학습 전에는 지문·자료와 이번 회차 읽기 기술만 표시합니다. 질문 목록·선택지·정답·근거 설명은 노출하지 않습니다.
- 학습 시작 후 한 문제씩 표시하고 현재 단계(첫 답, 확신, 근거, 확인, 재독, 힌트, 해설)를 안내합니다. 해결한 문제에서만 다음 문제 버튼이 활성화됩니다.
- 콘텐츠와 V2 저장 구조는 변경하지 않았습니다. 모바일 375px, 기존 완료 기록 유지, 재독 해결 후 다음 문제 이동 및 새로고침 복원을 재검증했습니다.

## 영어 탐험 V1 · 1주차 체험

`http://localhost:4173/english/`에서 확인합니다. 서버 실행은 위와 같이 `node scripts/serve.cjs`입니다.

- A 읽기 8문항: cat / book / happy → 학교 소개 → 위치 → 가방 색 → 사과를 받는 사람 → 장화 신는 순서.
- B 듣기 7문항: 사과 → 아침 인사 → 연필 개수 → 강아지 위치 → 과일 취향 → 우산 이야기 → 숙제 뒤 행동.
- C 말하기 6활동: Hi! → I like pizza. → I can swim. → 취향 선택 → 할 수 있는 행동 선택 → 세 문장 자기소개.
- 2주 이후 콘텐츠는 아직 없습니다. 실제 반응으로 다음 난도를 정합니다. 10~15분은 목표 시간이며 제한 시간은 없습니다.
- 문제는 한 번에 하나씩 진행합니다. 오답에는 재고려 기회를 주고, 필요한 경우 힌트와 해설을 읽은 뒤 이해 확인을 받습니다. 아이 화면에 점수·레벨을 표시하지 않습니다.
- 듣기 원문은 해결/해설 전까지 DOM에 넣지 않습니다. 버튼으로 Web Speech API를 호출하고, 실제 재생 시작과 종료 이벤트를 기록합니다. 기기의 소리 출력 자체를 자동 판정하지는 못합니다.
- 재생 오류·미지원·시작/종료 시간 초과 시 안내합니다. 듣기를 남겨두면 미실시로 기록하고 다른 활동으로 이동할 수 있습니다. 이를 정답으로 집계하지 않습니다.
- 말하기는 녹음·마이크·자동 발음 평가 없이 자기보고로 기록합니다. ‘오늘은 듣기만’ 선택과 말하기 느낌(선택)도 구별합니다.

### 영어 저장 및 부모 기록

오직 `heeyoon-english-board:v1`에 저장합니다. 기존 키를 읽거나 쓰지 않습니다. 첫 답은 첫 ‘답 확인’ 기준입니다.

- 공통: 주차/회차, 문항별 첫 답·최종 선택·시도 이력, 힌트/해설 사용, 해결 유형, 완료 날짜.
- B: 첫 재생 날짜, 재생 시작/완료 횟수, 재생 오류, 음성 미실시. 다시 듣기는 `재생 시작 횟수 - 1`입니다.
- C: 선택 표현과 말한 문장, 말해봤어요/듣기만, 도움, 편했어요/쑥스러워요/도움 필요 자기보고.
- 부모 영역에서 첫 선택 정답, 재고려 해결, 힌트, 다시 듣기, 말하기 완료, 도움과 느낌을 집계합니다. 자동 레벨 판정은 없습니다.
- 영어 회차를 열거나 완료해도 메인 영어 미션은 자동 완료되지 않습니다. 기존 영어 요일(화·목·토 기본값), 사용자 설정, 시간 기록을 유지합니다.

### 공통 선택 UX 원칙

- 단일 선택·토글 UI는 특별한 이유가 없다면 선택된 항목을 다시 눌러 해제할 수 있게 합니다. 다른 항목을 누르면 선택을 교체합니다.
- 직접 입력으로 선택한 값도 명시적인 취소 방법을 제공해 미선택 상태로 돌아갈 수 있게 합니다.
- 현재 적용 범위는 오늘 계획 화면입니다. 학습 완료 등 기존 기록에 영향을 주는 기능은 별도 요청 없이 변경하지 않습니다.
